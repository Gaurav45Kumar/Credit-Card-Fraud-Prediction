# Credit Card Fraud Detection System

A machine learning solution for identifying fraudulent credit card transactions using logistic regression and strategic under-sampling techniques.

## 📊 Project Overview

This project addresses the critical challenge of detecting fraudulent credit card transactions from a highly imbalanced dataset. Using machine learning and data resampling techniques, the system can accurately distinguish between legitimate and fraudulent activities with 94% accuracy.

## 🎯 Key Features

- **High Accuracy**: 94% accuracy on test data
- **Imbalance Handling**: Strategic under-sampling to address class imbalance
- **Model Interpretability**: Clear statistical analysis and feature importance
- **Scalable Solution**: Modular code structure for easy extension

## 🛠️ Technologies Used

### Programming & Libraries
- **Python** - Primary programming language
- **Pandas** - Data manipulation and analysis
- **NumPy** - Numerical computations
- **Scikit-learn** - Machine learning algorithms and model evaluation

### Machine Learning Techniques
- **Logistic Regression** - Classification algorithm
- **Under-sampling** - Data resampling technique
- **Stratified Sampling** - Data splitting method
- **Accuracy Score** - Model evaluation metric

## 📁 Dataset

The project uses a credit card transaction dataset containing:
- **284,807 transactions** in total
- **492 fraudulent transactions** (0.172% of total)
- **31 features** including time, amount, and PCA components (V1-V28)

### Class Distribution
- **Class 0**: 284,315 legitimate transactions
- **Class 1**: 492 fraudulent transactions
